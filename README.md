# Promote by Techverse

The application lives in **[promote](./promote)**. MC Henry is the first configured business.

See **[the app README](./promote/README.md)** for installation, setup, feature coverage and production configuration.

```powershell
cd promote
npm.cmd install
npm.cmd run build
npm.cmd start
```

Open `http://localhost:3000`, then `/setup` to create your own administrator login. No default passwords are embedded in the application.
